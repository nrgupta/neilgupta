College Courses

EECS 485 Web Systems
▼
Concepts surrounding web systems, applications, and internet-scale distributed systems. Topics include client/server protocols, security, information retrieval and search engines, scalable data processing, and fault-tolerant systems. Substantial projects involving development of web applications and web systems.
EECS 376 Foundations of Computer Science
▼
Introduction to theory of computation. Models of computation: finite state machines, Turing machines. Decidable and undecidable problems. Polynomial time computability and paradigms of algorithm design. Computational complexity emphasizing NP-hardness. Coping with intractability and exploiting it: cryptography.
EECS 370 Computer Organization
▼
Basic concepts of computer organization and hardware. Instructions executed by a processor and how to use them in assembly-language programs. Stored-program concept. Data-path and control for multiple processor implementations. Performance evaluation, pipelining, caches, virtual memory, and input/output.
EECS 281 Data Structures and Algorithms
▼
Algorithm analysis and O-notation. Fundamental data structures including lists, stacks, queues, priority queues, hash tables, binary trees, search trees, balanced trees, and graphs. Searching and sorting algorithms, recursive algorithms, basic graph algorithms, greedy algorithms, and divide and conquer strategy.
MATH 215 Multivariable Calculus
▼
Continuation of single-variable calculus into multiple dimensions. Topics include partial derivatives, multiple integrals, vector fields, line and surface integrals, and the theorems of Green, Stokes, and Gauss. Emphasis on concepts and problem-solving.
MATH 214 Linear Algebra
▼
An introduction to matrices and linear algebra. Covers the basics needed to understand applications ranging from linear programming to mathematical economics. Topics include systems of equations, determinants, eigenvalues, and vector spaces. Designed for engineering students needing strong linear algebra foundations.
